# Airbnb Design System Tokens

## Color Palette
- **Primary Accent**: `#FF385C` (Airbnb Rausch Coral)
- **Primary Hover**: `#E00B41`
- **Dark Text**: `#222222` (Heading & primary body)
- **Muted Text**: `#717171` (Subtitles, ratings count, metadata)
- **Light Gray Border**: `#DDDDDD`
- **Soft Background Gray**: `#F7F7F7`
- **Dark Overlay**: `rgba(0, 0, 0, 0.92)` (Lightbox backdrop)

## Typography Stack
- Font Family: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
- Listing Title: `26px / 30px`, font-weight `600`
- Section Heading: `22px / 26px`, font-weight `600`
- Body Text: `16px / 24px`, font-weight `400`
- Price Tag: `22px`, font-weight `600`

## Spacing & Radius Scale
- Grid Gap: `8px` for hero photo collage, `16px` / `24px` for content sections
- Rounded Corners: `12px` for photo cards, hero collage corners, and reservation widget box
- Button Radius: `8px` or `9999px` (pill)
- Box Shadow: `0 6px 16px rgba(0, 0, 0, 0.12)` for sticky reserve card
